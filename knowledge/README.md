# Ghi chú kiến thức riêng của anh

Bỏ vào thư mục này các file `.md` hoặc `.txt`: chiến lược, kinh nghiệm, quy tắc giao dịch riêng...

Khi viết bài Kiến thức, AI sẽ **ưu tiên** dùng nội dung trong đây (nếu liên quan tới chủ đề hôm đó),
để bài mang góc nhìn riêng của page thay vì kiến thức chung chung.

Gợi ý đặt tên file theo chủ đề, ví dụ: `quan-ly-von.md`, `chien-luoc-vang-phien-my.md`.
